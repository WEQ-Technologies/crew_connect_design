Revision 4 · Association & Forum module
Official notices from Associations and Forums

Two entity types — Association and Forum — publish official notices; everyone else reads them on a read-only Forum Wall. No likes, reactions, comments, user posts, follow/connect, sharing, engagement metrics or withdrawal. All screens below are the live prototype screens, running on the mock data in crewconnect_content.json › assoc_module (10 entities, 16 notices).

Data model and backend hand-off
Entity
id · name · type (Association | Forum) · logo · short description · region (optional) · status (active | inactive) · posting access (issued | revoked) · departments · login email
Notice
id · entity (posted by) · title · body · departments[] (mandatory, from the existing department master list) · attachment (optional PDF) · postedAt · editedAt (nullable). No withdrawn status.
Not yet available — needs backend
Entity accounts on the existing auth service (role = association | forum, entityId) · notices API (list with type / entity / department filters, create, update, delete scoped to the signed-in entity) · PDF upload and file URLs · admin controls for status and posting access. The prototype simulates these with mock data and session-only changes.
