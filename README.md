# CrewConnect — Phase 1 Glassmorphism Final Design (Prototype Review Link)

This repository hosts the interactive iPhone prototype for CrewConnect on Vercel:
**[https://www.crewconnect.review-link.in/](https://www.crewconnect.review-link.in/)**

## Structure

- `index.html` — The standalone, self-contained single-file bundle containing the complete Phase 1 Glassmorphism Final Design (all 63 screens, fonts, styles, and assets packed in-memory).
- `vercel.json` — Static hosting configuration, headers, and fallback redirects for legacy URLs (`/Prototype.dc.html`, `/Journeys.dc.html` → `/`).
- `.gitignore` — Standard gitignore for Vercel and editor artifacts.
