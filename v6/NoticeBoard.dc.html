Association forum wall
Notice details — four content variants, one read-only screen
The same screen renders whatever an association admin posts: formatted text, wide tables, payment details or plain unformatted text. Forums are read-only: no likes, dislikes, shares, comments or attachments; the association logo leads every notice. Key details and the Add to calendar / Pay action appear only when the notice carries a date or an amount.

Event · headings, lists, bold / italic, link, quote, key details with Add to calendar
2 · Table-heavy
5-column rate table scrolls sideways with a sticky first column; “View as cards” stacks rows on narrow screens
3 · Payment notice
Payment · due date, amount and late fee with Pay now. Attachments removed: Forums are read-only
4a · Plain text, very short
One unformatted sentence: no key details, no attachments; the layout stays balanced
4b · Plain text, long
All-caps title, pasted text with line breaks and a 120-character URL that wraps instead of overflowing
